Select propagated hidden or final channels. The P1 paper profile uses within-layer feature windows with explicitly named r0 sampling laws. The pinned 778f0d0 profile excludes the first affine output, permits cross-layer windows and retains possible feature/target overlap. Uniform unrestricted selection is a separately chosen alternative. These are selection policies, not complete paper reproductions.

Currently requires equal-width sequential single-expert layers without gates or skips. Dense, individual sparse and block sparse sources are supported, including their sampled weights, activation/dropout laws, internal noise/importance, coordinate roots and prototype banks. Source and task adapter controls are editable in the JSON below. Preserve source output width even when the observation target uses fewer channels. Variable widths, residual/skip/gated and irregular selection policies remain required extensions; invalid architectures reject without resampling or substitution.
