Typed categorical converter pipelines

A converter captures one category before structural noise and node importance. Descendants receive a numeric representation with the original span width. This is different from the native one-hot node family. Fits use independent ancestor populations; reopening never refits query rows.

Vocabulary size is explicit. Softmax weights affect logits, not guaranteed category frequencies. Full JSON controls topology, latent widths, root/function catalogs, parent composition, numerical converters and optional r0 innovations. Catalog choices sharing a cached name must agree, or use the explicit refresh policy.
