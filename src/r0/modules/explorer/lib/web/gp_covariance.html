Retained GP population matrices

Inspect the selected retained population/environment, independently of the rows selected in the generation graph. The covariance is K, its lower triangular factor is L, and each GP column is X = LZ. For GP-root DAGs these columns feed the root equations; observed features and targets appear in the generation graph. The selected environment uses its own retained matched/fresh innovations; both target sides keep the same feature draw. These are saved construction values; this view does not condition, resample or fit the population.
