Construct a graph or standalone network

Sample frozen mechanisms and retain their construction draws, or author a native mixed-domain graph. Authored native equations/domains are fixed controls. Sampled native priors use the construction seed; emitted rows use the dataset seed. Construction and generation replay run under the selected timeout. Pair creation also guards preparation and comparison.

Sample native variable kinds, cardinalities, frequency laws, emissions and cutpoints on an explicit DAG. Edit each domains entry: kinds (continuous, binary, categorical), cardinalities, emissions (softmax, argmax, threshold), frequency_laws (uniform, dirichlet, logistic-normal), threshold_laws (normal-quantile, uniform-quantile, sorted-normal), concentration, temperature and threshold_scale bounds. Uniform is an r0 baseline; configurable symmetric Dirichlet hyperpriors, frequency-logit offsets and reference cutpoints are adaptations; logistic-normal is an extension. Frequency weights do not guarantee marginal class frequencies. Sorted-normal cutpoints ignore frequency weights. Observed channels and target are explicit; target type/classes follow its sampled domain, with at most 100 target classes. Scalar native nodes contain one continuous vector or discrete variable. The heterogeneous vector presets use an ordered domains array per node: one joint score equation, then per-variable emissions. Readout indices select logical variables; children receive concatenated continuous and one-hot blocks. Additional source laws remain required work. For asymmetric Dirichlet, set a domain version to native-asymmetric-domain-prior-v1, select asymmetric-dirichlet, and supply concentration_vectors with one positive vector per reachable cardinality. Vector entries are absolute concentrations; scalar concentration is unused for this r0 extension. Root and child function catalogs must share compatible named contracts. Rows, context_rows and split here control this construction; dataset shape settings above do not override them.

Parent composition controls: source tabiclv2 selects concat or per-parent aggregate with sum, product, max or logsumexp. Source mitra2 reduces the joint nonlinear output together with independent parent projections for multi-parent nodes; mode must remain sample. Mean, weighted, MLP, product and max are available; weighted/neural sampling laws are explicit r0 adaptations. Source extension offers the broader catalog. Optional numerical pipelines operate after the frozen parent function; native variants retain typed node domains.

Explicit/Cauchy controls edit parents, widths and channel pairs. Geometry sampling chooses widths and feature-node assignments. Attachment is an r0 extension; recursive motifs and rewrites are r0 adaptations, not exact published prior reproductions. Edit all topology controls in the topology_prior object. Choose root families and function priors. Plain geometry defaults to identity numerical readouts and adapter-score targets. An optional pipeline_prior object enables channel importance, L2, Gaussian noise, node importance and numerical converters for any geometry topology. Pipeline presets expose all switches, weight/scalarization choices and converter restrictions. Historical tuple transforms descendant state but captures the raw readout; historical graph transforms both; readout-only transforms the readout and preserves descendant state. Readouts precede innovation and node importance. Readout-only and frozen independent fitting are explicit adaptations; these are numerical pipelines, not native categorical variables. Keep noise_scale zero when using the sampled pipeline noise prior. These controls are separate from the dataset settings above.

Empty uses default causal limits. Explicit larger caps also authorize replay and inspection. Graph inspection, the mechanism editor and pair reopening run synchronously under these caps, outside the generation timeout. Workloads are not promised at every combination of maxima.
