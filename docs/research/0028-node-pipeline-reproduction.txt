## Reproduction

Use the existing environment; install nothing. From the candidate repository cwd,
set `PYTHONPATH` to its `src`, `OMP_NUM_THREADS=1`, `MKL_NUM_THREADS=1`, and
`PYTHONDONTWRITEBYTECODE=1`. Run the retained `verify.py` with the existing Python.
Its output is relative to its own directory; copy the four scripts into a fresh
evidence directory for a fresh run. Preserve both pinned git objects for audit.

Run `legacy.py` twice with the same Python, each time setting `LEGACY_OUTPUT` to
`legacy-baseline.json` or `legacy-candidate.json` in that evidence directory. The
baseline run must set `PYTHONPATH` to `<evidence>/baseline/src`; the candidate run
must point it to the candidate `src`. Export baseline `src` with git archive first.
Run `audit.py` after those captures and `verify.py`. Run Ruff from repository cwd
against all four files. `custody.py` is the common receipt helper.
