# Explicit topology hyperprior envelopes

`TopologyHyperprior` draws log-size uniformly between declared log endpoints, exponentiates in binary64, and uses the selected `floor`, `ceil` or nearest-even integer rule. `FixedSizeTopologyHyperprior` is a separate explicit profile: it retains its integer size and never draws or reports an unused log-size. Both draw a unit-scale Gamma variate with declared shape and divide by the declared rate. Positive finite shape/rate, bounded size ranges and component counts are explicit controls; bounds must fit caller limits before sampling.

TabPFN-v2's graph-structure section describes log-uniform size, a Gamma redirection parameter and disjoint components. It does not specify integer rounding or conversion of unbounded Gamma to a probability. This implementation provides two **named r0 reconstructions**: `gamma-odds-r0`, P=G/(1+G), and `gamma-exp-r0`, P=1-exp(-G). Stable equivalent formulas avoid avoidable intermediate overflow/cancellation. Floating-point rounding can reach an endpoint for extreme finite inputs; no clipping or rejection-resampling is used. Nonfinite values and Gamma underflow to zero fail explicitly and roll back the caller stream. This is not a uniquely specified or full reproduction of the paper's prior. [Primary Methods section](https://www.nature.com/articles/s41586-024-08328-6), [primary open-access article](https://pmc.ncbi.nlm.nih.gov/articles/PMC11711098/).

`sample_topology_hyperprior(request, rng=..., limits=..., raw_limits=...)` returns `SampledTopologyHyperprior`. It retains the original request, log/Gamma/scaled-Gamma values, transformed `CausalGraphPrior`, balanced contiguous component spans, every integer predecessor choice and redirect uniform, final parent adjacency, and initial/final JSON snapshots for the injected NumPy engine. The balanced allocation policy is explicit r0 behavior. Every non-root node selects one earlier node in its component, and redirects to that node's predecessor when the uniform is below P and that predecessor exists. Components have no cross-edges.

There are exactly N-C edges for N nodes and C components, independently of P. P changes ancestry/depth/degree, not this forest's edge density. The paper's density statement is preserved as an unresolved source discrepancy; this implementation does not invent extra edges to match it. Existing forward, layered, redirection, Cauchy, attachment and motif graph families are unchanged.

Admission uses the largest configured node count before RNG cloning or draws, including metadata/array work, complete raw call/value/header caps and snapshot copies. These conservative reservations are not measured process RSS. Actual complete-record costs are checked against the admitted reservation before replay. Five supported engines preserve exact raw primitive types, snapshots and draw order. Sampling commits the caller state only after complete validation. `replay()` and the complete public decoders reject malformed/missing fields, changed raw records, derived quantities, component/parent assignments and inconsistent snapshot chains; caller limits precede restoration.

This first slice is the immutable topology construction core. Integration with sampled mechanism/task identity, archive/workflow transport, requested-versus-realized workbench geometry and across-seed views remains required in subsequent coherent slices. Keep the retained sampled topology when later task execution fails; never silently resample size or select a graph by numerical usefulness. No full-paper, hosted/GPU, large-scale resource or complete-workbench acceptance is claimed by this core.
