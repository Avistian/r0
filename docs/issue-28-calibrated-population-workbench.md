# Guarded fixed-calibration population workbench

The population workbench has an explicit independent calibration action. The user
selects fit row count (32–4096), fit seed and fit task ID. The current raw population
and all its row-owned mechanisms remain in the resulting archive. Calibration runs
inside the bounded generation worker, with complete original and proposed fit
geometry admitted before source replay. The fit seed is also the recorded
construction seed for this operation; no unused random control is claimed.

For a calibrated dataset, **Next query · fixed calibration** constructs only a new
query population. It retains the complete source lineage, original independent fit
and constants. The ordinary episode seed/task controls identify the query; the
construction seed controls its row-forest stream and the population RNG selector
supports all five engines. **Replay retained original population** replays the
current query exactly. Fit details show the independent identity and constants;
large integer identities remain decimal strings through browser transport.

Matched and fresh population interventions use the same retained fit on both
sides. Original-row traces retain calibration and adapter dependencies, and both
task and pair archives support reopen/export. Functional regression/classification,
native scalar, heterogeneous native vector and converted continuous targets keep
their existing semantics. Category-valued targets retain category codes; they are
not numerically standardized. Geometry/law changes require explicit new raw
population construction and a new fit. Task-only adapter comparisons remain required separately from causal interventions.
A linked recalibration comparison remains
a separately required extension, not an implicit edit.

Construction, replay, traces and comparisons run under caller time, memory and
archive limits. The aggregate estimate includes retained history and independent
fit populations, so a fit can require explicitly larger limits than a raw task.
The interface does not raise those limits automatically. Failed operations retain
failure receipts and the prior active dataset. Complete archived JSON remains
available; source controls describe a new raw construction rather than modifying
the retained fit in place.

The same session actions serve local browser and notebook callbacks. Actual hosted
Colab, GPU, scientific distribution fidelity and maximal workloads are not claimed.
Calibrated original-row response curves remain required reference composition;
no uncalibrated curve is silently substituted. Source-paper limitations of the
underlying recursive forest and fixed-calibration extension remain unchanged.
