## Before and after

The initial public tests failed for RFF and periodic length scales `1e13` and
`1e200`, and for evaluating a polynomial on otherwise finite inputs with huge
inactive columns. The first four failures were calibration rejections; the fifth
was a nonfinite evaluated signal. All six final tests pass, including an extreme
polynomial generation/graph case. Active overflow is still rejected.

The final standalone edge walkthrough generated **18 cases**: RFF and periodic at
both length scales, an extreme polynomial and a composition, each for regression,
binary and three-class classification. Every case replays exactly and has zero
signal/target graph reconstruction error. Independent scalar row calculations for
the non-composed cases have maximum absolute error **2.220446049250313e-16**.
Two deliberate invalid cases—Fourier length scale `1e-320` and polynomial input
scale `1e200` at degree 16—fail visibly. Failures are retained separately from the
18 successful cases; no replacement draws or silent retries occur.

A separate pre-fix checkout generated **18 ordinary baseline tasks**: RFF,
periodic and polynomial × three task types × seeds 3 and 27. The corrected runtime
replayed all inputs, scores, targets and class probabilities exactly, with unchanged
mechanism JSON and source/episode identities. This is evidence for those 18 cases,
not an assertion that every possible float calculation has been exhaustively tested.

Browser checks generated the weak RFF case and extreme polynomial through the
bounded explorer runner. They checked the centered-cosine graph formula, a finite
nonconstant weak-function response curve, zero inactive polynomial basis entries,
zero graph reconstruction error and an empty browser exception list. Screenshots
retain the actual graph and matrix views.

## Checks and limits

At runtime `b722222`, `make check` passed: **472 passed, 1 CUDA skip in 129.51 s**.
The required `make smoke` and `make eval-smoke` followed in order, both exiting 2
because the `train` and `eval` CLI commands are absent. Their logs are retained;
there is no training loss summary or evaluation table.

The scientific review found no defects in the constant shift, independent
calibration, replay compatibility or graph alignment. Standards review found no
hard violation and an optional readability suggestion for the independent scalar
walkthrough. The early type check caught an untyped NumPy parts list; its explicit
annotation is included in the final passing source. Preliminary uncommitted probes
were not used as revision-qualified acceptance evidence.

GPU agreement, hosted Colab/Drive execution, broader sampling profiles, bounded
training consumption and resource/scale measurements remain pending #27 work.
